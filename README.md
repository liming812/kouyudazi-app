# 口语搭子

AI 英语口语陪练桌面应用。按住说话和 AI 对话，逐句朗读中文释义，点词收藏进个人词库，AI 自动带你复习重点词。

## 使用前提

- 千问 AI 平台 Token Plan 的 API Key（[platform.qianwenai.com/pricing/token-plan](https://platform.qianwenai.com/pricing/token-plan) 购买），首次启动在「系统设置 → 供应商设置」填入
- 口语对话需要麦克风

## 主要功能

**口语对话**
- 按住说话与 AI 实时口语练习，支持随时打断
- 不想说的时候也可以文字输入
- AI 回复逐句朗读，附中文释义，走路通勤也能练听力

**词库**
- 从网站选择词汇范围（小学/中考/高考/四六级等），下载 CSV 导入个人词库
- 对话中点击任意单词查询、收藏、标注掌握程度（新学/待学/巩固/熟练/困难）
- 已导入的词离线秒查，不消耗 API
- AI 对话时自动参考词库中的重点词，针对性带你练习

**会话分析**
- 整段对话语言点分析，可选思考模式深挖问题

**多模型**
- 6 个模型可切换，对话与分析可独立开关思考模式

## 数据与隐私

- 所有数据（API Key、词库、会话记录）仅保存在本机用户目录，不上传任何服务器
- 应用不内置任何单词数据，词库内容完全由用户自己选择导入
